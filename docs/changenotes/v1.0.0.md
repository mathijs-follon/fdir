# v1.0.0

First stable release of the C-only `fdir` API. This version consolidates all breaking changes since v0.2.0.

[README](https://github.com/mathijs-follon/fdir/blob/main/README.md) | [API reference](https://github.com/mathijs-follon/fdir/blob/main/docs/api.md) | [Integration guide](https://github.com/mathijs-follon/fdir/blob/main/docs/integration.md)

## Breaking changes

**Port integration is explicit and fully required**

Weak default port hooks in `src/port.c` are removed. Three platform callbacks must be supplied through a `fdir_port_t` passed to `fdir_init()`:

```c
fdir_port_t port = {
    .get_now_ms     = platform_now_ms,
    .emit_event     = platform_emit_event,
    .request_reboot = platform_request_reboot,
};

fdir_status_t status = fdir_init(&cfg, &port);
if (status != FDIR_OK) {
    /* FDIR_ERR_PORT: port was NULL or a required callback was NULL */
}
```

Every required function pointer in `fdir_port_t` must be non-NULL. `fdir_init()` returns `FDIR_ERR_PORT` otherwise.

**Internal failure queue and supervisor tick**

Failure reports are queued inside the library (default depth 8). Workers call `fdir_report_fault()`; the supervisor calls `fdir_supervisor_tick()` to drain the queue and run watchdog checks. The **`submit_failure` port hook** is removed from `fdir_port_t`.

The library still exposes **`fdir_submit_failure()`** as an advanced C API that enqueues without changing entity health. Prefer `fdir_report_fault()` from worker context.

**C++ wrapper removed**

`include/fdir.hpp` and all C++ examples are removed. Use the C API only (`fdir.h`).

**Cooperative worker polling replaces forced isolation**

`isolate_current_worker` is removed from `fdir_port_t`. Worker loops use `fdir_worker_may_run(id)`:

```c
if (!fdir_worker_may_run(entity_id)) {
    continue;
}
```

It returns non-zero when system mode is below `FDIR_MODE_SAFE` and entity health is not `FDIR_HEALTH_FAILED`. In SAFE/REBOOT it heartbeats and returns zero so workers stay alive without doing work.

`fdir_pause_if_failed()` is removed. Use `fdir_worker_may_run()` in loops; use `fdir_entity_may_run()` for read-only checks only.

`fdir_report_fault()` enqueues a failure report and marks the entity failed only after a successful enqueue; it no longer calls a port isolation hook. On `FDIR_ERR_BUSY` (queue full), entity health is unchanged so the worker can retry.

**`fdir_init()` signature change**

```c
/* before (v0.2.0) */
fdir_status_t fdir_init(const fdir_config_t *config);

/* after (v1.0.0) */
fdir_status_t fdir_init(const fdir_config_t *config, const fdir_port_t *port);
```

## Also included

- Cooperative worker model (`fdir_worker_may_run`, no port isolation hook)
- Optional port `lock` / `unlock` for multi-threaded integrations ([threading.md](../threading.md))
- Fault latch / deduplication per entity+reason
- Uncapped restarts via `FDIR_RESTART_UNLIMITED` on entity budget fields
- Ground supervisor bypass via `fdir_set_supervision_enabled()`
- Richer events: `anomaly_id`, `severity`, `phase`, `level`; watchdog faults emit `FDIR_EVENT_WATCHDOG`; subsystem marks emit `FDIR_LEVEL_SUBSYSTEM` events
- Subsystem and system handlers; ground mode APIs
- Critical fault flag and `FDIR_ERR_BUSY` on queue rejection; `fdir_report_fault_ex()` for non-critical reports
- Latch query via `fdir_health_fault_is_latched()`; latch set/clear is internal to the supervisor
- Entity and subsystem names copied at registration (safe with stack-allocated name strings)
- Four flattened C examples under `examples/<name>/` (no `c/` / `cxx/` split): `getting_started`, `dual_path`, `filecopy`, `FreeRTOS`
- New `dual_path` example: satellite-style dual critical-path policy and SAFE escalation
- Integration guide ([integration.md](../integration.md)) and SEooC assumptions ([safety/seooC.md](../safety/seooC.md))
- 90 unit tests across 10 test modules
- `compile_commands.json` generation for IDE navigation

## Migrating from v0.2.0

1. Remove C++ wrapper usage; include `fdir.h` only.
2. Supply a complete `fdir_port_t` to `fdir_init()` (no weak defaults).
3. Replace port `submit_failure` with internal queue: workers call `fdir_report_fault()`, supervisor calls `fdir_supervisor_tick()`.
4. Replace `fdir_pause_if_failed()` / port isolation with `fdir_worker_may_run()` in worker loops.
5. Update example paths: sources live at `examples/<name>/main.c`.
