## Breaking changes

**`fdir_post_failure` renamed to `fdir_submit_failure`**

The name `post` was ambiguous between "submit/enqueue" and "power-on self-test". The runtime failure submission hook is now named `fdir_submit_failure` throughout the C API, the C++ `fdir::Port` struct, and all examples. Any existing port hook implementations must be renamed.

C:
```c
/* before */
int fdir_post_failure(const fdir_failure_report_t *r) { ... }

/* after */
int fdir_submit_failure(const fdir_failure_report_t *r) { ... }
```

C++:
```cpp
/* before */
fdir::Port{ .post_failure = [](const fdir::FailureReport &r) { ... } }

/* after */
fdir::Port{ .submit_failure = [](const fdir::FailureReport &r) { ... } }
```

## Also included

- All six examples now have a `c/` and `cxx/` subdirectory with idiomatic C and C++ implementations respectively
- All examples demonstrate startup self-testing: faults reported immediately after entity registration using the normal `fdir_submit_failure` / `fdir_handle_failure` path
- `make examples` builds all six example variants
- C++ wrapper `fdir::Port::submit_failure` updated
- Tests added for health, internal, recovery, subsystem, and report modules
- Test runner now builds and runs each test file independently
