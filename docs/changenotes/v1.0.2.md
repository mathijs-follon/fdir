# v1.0.2

Bug-fix release. No API changes.

[README](https://github.com/mathijs-follon/fdir/blob/main/README.md) | [API reference](https://github.com/mathijs-follon/fdir/blob/main/docs/api.md)

## Bug fixes

**Nested port lock in `fdir_entity_register()`**

Registration held the port sync lock and then called the locking `fdir_health_reset()`, causing self-deadlock when integrators supply a non-recursive mutex. Now uses `fdir_health_reset_unsafe()` under the held lock.

**Unsynchronised public mode mutators**

`fdir_enter_degraded_mode()`, `fdir_enter_safe_mode()`, and `fdir_try_reboot()` read and wrote `g_mode` without port sync when called from application code, racing locked readers such as `fdir_system_mode()`. Public entry points now take the port lock; supervisor-internal paths call `_unsafe` helpers while already holding the lock.
